# Unit Converter

A simple C program that converts temperature, distance, and weight units.

## Features

- Celsius to Fahrenheit
- Fahrenheit to Celsius
- Kilometers to Meters
- Meters to Kilometers
- Kilograms to Grams
- Grams to Kilograms

## C Concepts Used

- Variables
- Data types
- Input and output
- Format specifiers
- Arithmetic operators
- if-else statements

## Example

Input:
25 Celsius

Output:
77.00 Fahrenheit
